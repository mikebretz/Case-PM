# C++ source for Sylvorin (optional — not used when opening the project)

When you are ready for C++ development:
1. Move Source back to Unreal\Source
2. Add Modules back to Sylvorin.uproject
3. Install Visual Studio 2022 with "Game development with C++"
4. Right-click Sylvorin.uproject -> Generate Visual Studio project files

For now, open the game with OPEN-SYLVORIN-PROJECT.bat only.
