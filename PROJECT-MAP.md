## Batch files (at C:\Sylvorin)

| File | What it does |
|------|----------------|
| **INSTALL-DESKTOP.bat** | Run once — npm, Python, build, desktop shortcut |
| **RUN-DESKTOP.bat** | Play in desktop window |
| **RUN-SYLVORIN.bat** | Play in browser |
| **CLONE-TO-C-SYLVORIN.bat** | Clone GitHub repo to C:\Sylvorin |
