SYLVORIN — everything lives at C:\Sylvorin
============================================

NOT part of Case PM / KSPM.

FIRST TIME — get latest files from GitHub (no Pull Request needed):
  DOWNLOAD-SYLVORIN-FROM-GITHUB.bat

Then:
  SETUP-SYLVORIN.bat  (option 4 = check, option 2 = open Unreal)

  Then always:
    C:\Sylvorin\INSTALL-DESKTOP.bat

FILES AT C:\Sylvorin:
  INSTALL-DESKTOP.bat     setup (run once)
  RUN-DESKTOP.bat         play game
  RUN-SYLVORIN.bat        play in browser
  desktop_launcher.py     desktop window
  src\game\               all game code
  index.html              game page

GitHub: https://github.com/mikebretz/Sylvorin
