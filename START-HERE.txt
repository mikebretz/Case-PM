SYLVORIN — everything lives at C:\Sylvorin
============================================

NOT part of Case PM / KSPM.

FIRST TIME SETUP:
  Option A — one-click pull (after PR is merged / branch exists):
    PULL-TO-C-SYLVORIN.bat

  Option B — git clone:
    git clone -b cursor/sylvorin-c-drive-c4a4 https://github.com/mikebretz/Case-PM C:\Sylvorin

  Option C — copy files:
    COPY-TO-C-SYLVORIN.bat

  Then always:
    C:\Sylvorin\INSTALL-DESKTOP.bat

FILES AT C:\Sylvorin:
  INSTALL-DESKTOP.bat     setup (run once)
  RUN-DESKTOP.bat         play game
  RUN-SYLVORIN.bat        play in browser
  desktop_launcher.py     desktop window
  src\game\               all game code
  index.html              game page
