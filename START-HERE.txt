SYLVORIN — everything via GitHub pull
======================================

Repo: https://github.com/mikebretz/Sylvorin

STEP 1 — Pull files to C:\Sylvorin
  PULL-FROM-GITHUB.bat
  (or SETUP-SYLVORIN.bat option 6)

STEP 2 — Fix "Unreal not found" (UE 5.8 running)
  FIND-MY-UNREAL.bat   (run while Unreal is open)
  OR SET-UNREAL-PATH.bat (paste path manually)

STEP 3 — Open game
  SETUP-SYLVORIN.bat option 2
  OR File -> Open Project in Unreal:
    C:\Sylvorin\Unreal\Sylvorin.uproject
