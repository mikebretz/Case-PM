SYLVORIN — GitHub download
============================

Repo: https://github.com/mikebretz/Sylvorin

FIRST TIME (empty Sylvorin repo on GitHub)
  1. DOWNLOAD-SYLVORIN-FROM-GITHUB.bat   (gets files to C:\Sylvorin)
  2. PUBLISH-SYLVORIN-TO-GITHUB.bat      (ONE TIME — uploads to Sylvorin repo)
     Sign in to GitHub if prompted.

AFTER Sylvorin repo has files
  PULL-FROM-GITHUB.bat                   (git pull)
  or DOWNLOAD-SYLVORIN-FROM-GITHUB.bat   (zip download, no git)

OPEN GAME
  OPEN-SYLVORIN-PROJECT.bat
  SETUP-GAME-NOW.txt

Backup source (if Sylvorin repo empty):
  Case-PM branch cursor/sylvorin-c-drive-c4a4
